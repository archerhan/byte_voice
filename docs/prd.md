# ByteVoice — 纯离线语音转写笔记工具

## 1. 概述

 **ByteVoice** 是一款纯离线的语音转写笔记工具，运行在 macOS 上（后续拓展至 iOS）。
核心能力：录音或导入音频文件 → VAD 切分语音段 → ASR 转写文字 → 带时间轴的笔记管理。
全程离线，数据存在本地，无联网、无账号、无云端。

### 核心理念

- **离线优先**：所有处理在端侧完成，不需要网络连接
- **隐私安全**：音频和转写数据全部存储在本地，不离开设备
- **效率工具**：面向需要快速从语音获取文字的 macOS 用户
- **扎实基础**：先把「语音 → 文字」做深做透，不盲目堆功能

### 目标用户

- 需要把会议、访谈、课程、头脑风暴录音快速转写文字的 macOS 用户
- 记者、学生、产品经理、独立研究者

### 技术栈

| 模块 | 选型 | 说明 |
|------|------|------|
| 框架 | Flutter 3.x | 跨平台 UI，macOS 优先 |
| 状态管理 | Riverpod | 轻量，对 Stream 支持好，适合音频流场景 |
| 数据库 | drift | 类型安全 SQLite 封装，代码自动生成 |
| 音频采集 | record | Dart 包，macOS/iOS 原生 PCM 输出 |
| 音频解码 | ffmpeg_kit_flutter_new | 文件导入场景，支持常见音频格式 |
| 后台任务 | workmanager | macOS 支持 BGTask，文件转写后台运行 |
| 本地通知 | flutter_local_notifications | 转写完成弹系统通知 |
| ASR+VAD 引擎 | sherpa_onnx (Dart) | 统一封装 SenseVoice + Silero-VAD |
| 文件选择器 | file_selector | 平台原生文件选择对话框 |
| 拖拽导入 | desktop_drop | macOS 拖拽文件进窗口 |

## 2. 不支持的功能（第一版明确不做）

- TTS（文字转语音）
- 说话人分离 / 识别
- 账号系统、云同步
- 联网服务、在线模型
- 声音克隆
- 实时翻译
- 语音意图识别

## 3. 系统架构

四层架构，每层职责单一，上层依赖下层定义的接口。

```
┌─────────────────────────────────────────────────────────┐
│  UI Layer (Flutter Widgets)                              │
│  - 主窗口布局（侧边栏 + 内容区 + 工具栏）                │
│  - 笔记列表 / 笔记详情 / 实时转写流 / 导入进度         │
│  - 设置窗口                                              │
├─────────────────────────────────────────────────────────┤
│  State Management (Riverpod)                             │
│  - 全局状态: AppSettings, ActiveTranscription            │
│  - 异步: StreamProvider 实时转写结果流                   │
│  - FutureProvider: 笔记列表查询                          │
├─────────────────────────────────────────────────────────┤
│  Repository Layer (drift)                                │
│  - NotesRepository: 笔记 CRUD + 搜索                     │
│  - SegmentsRepository: 片段批量写入 / 查询               │
│  - SettingsRepository: 键值对存储                        │
├─────────────────────────────────────────────────────────┤
│  Service Layer (Dart)                                    │
│  - TranscriptionService: 录音状态机 + VAD+ASR 编排       │
│  - AudioImportService: 文件解码 + 分批 VAD/ASR           │
│  - ModelDownloadService: 模型下载 + 校验 + 加载           │
│  - ExportService: TXT / MD / SRT 导出                   │
│  - NotificationService: 本地通知管理                    │
├─────────────────────────────────────────────────────────┤
│  Engine Layer (sherpa_onnx Dart 包)                      │
│  - VAD: Silero-VAD 模型 → 语音片段检测                 │
│  - ASR: SenseVoice 模型 → 片段转文字                     │
│  - （预留）Speaker Embedding → 未来说话人分离           │
├─────────────────────────────────────────────────────────┤
│  Audio Layer (Dart packages)                             │
│  - 麦克风采集: record                                    │
│  - 文件解码: ffmpeg_kit_flutter_new                      │
│  - 拖拽文件: desktop_drop                               │
└─────────────────────────────────────────────────────────┘
```

### 设计原则
- **引擎层只有纯函数式调用**：VAD 和 ASR 不持有状态，输入 PCM 片段，输出结果
- **TranscriptionService 状态机**管理录音生命周期：Idle → Recording → Paused → Done
- **文件转写走同一套管线**：文件解码成 PCM 流后以相同方式送入 VAD+ASR
- **Repository 层隔离 SQLite 细节**：Service 只跟纯 Dart Model 打交道，不碰 SQL
- **保持克制**：不引入不必要的抽象层，分层是为了隔离而非架构表演

## 4. 数据模型

### Note（笔记）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| title | String | 自动生成（首句截取）或用户编辑 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 最后修改时间 |
| durationMs | int | 音频总时长（毫秒） |
| audioFilePath | String? | 音频文件路径，null 表示未保留 |
| keepAudio | bool | 是否保留原始音频 |
| source | enum: recording / import | 来源 |
| status | enum: transcribing / completed / failed | 转写状态 |
| currentProgress | double? | 转写进度 0.0~1.0（文件导入专用） |

### Segment（转写片段）

每个 Segment 对应 VAD 识别出的一个语音片段 + ASR 返回的文字。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| noteId | String (FK→notes) | 关联笔记 |
| startMs | int | 在音频中的起始时间（毫秒） |
| endMs | int | 结束时间（毫秒） |
| text | String | 转写文字 |
| confidence | double? | ASR 置信度，预留 |
| sortIndex | int | 片段顺序号 |

### Settings（设置，键值对）

| 键 | 默认值 | 说明 |
|----|--------|------|
| asr_model | sensevoice_small | ASR 模型版本 |
| vad_sensitivity | 0.5 | VAD 阈值 0.0~1.0 |
| keep_audio | false | 是否保留原始音频文件 |
| export_format | txt | 默认导出格式 |
| language | zh | 语言偏好 |

## 6. 核心流程

### 实时录音转写

```
① 用户点击录音 → 申请麦克风权限（首次）
② 麦克风采集 PCM 流（16kHz, mono, float32）
③ VAD 检测语音活动 → 检测到有人说话开始缓冲
④ VAD 检测到说话结束 → 完整语音段送 ASR
⑤ ASR 返回转写文本 → 写入 segments 表
⑥ Riverpod StreamProvider 通知 UI 更新
⑦ 用户点击完成 → 停止采集 → 刷新缓冲区 → 保存笔记
```

### 文件导入转写

```
① 用户选择文件或拖拽 → 格式校验
② ffmpeg 解码为 16kHz mono PCM（分块读取）
③ VAD 逐段检测 → 输出语音片段列表
④ 语音片段批量送 ASR（每完成一批更新进度）
⑤ 全部完成后一次性写入 notes + segments 表
⑥ 发本地通知 → 用户可跳转查看
```

### 转录状态机

```
Idle ──startRecording()──→ Recording ──pauseRecording()──→ Paused
                            ↑                               │
                            └─────resumeRecording()─────────┘
                            │
                            └──stopRecording()──→ Done
                                                     │
                                                     └──closeNote()──→ Idle

文件转写简化版：Idle → Importing → Transcribing → Done
```

## 7. 模型管理

### 模型清单

| 模型 | 类型 | 预估大小 | 说明 |
|------|------|----------|------|
| SenseVoice Small | ASR | ~60MB | 默认，中英日粤等 |
| Silero-VAD | VAD | ~15MB | 语音活动检测 |

### 下载策略

- 首次启动自动将模型下载到 `Application Support/byte_voice/models/`
- 支持断点续传（记录已下载字节数）
- 下载完成后校验 sha256，校验失败自动重下
- 下载失败（无网络等） → 显示错误页 + 重试按钮
- 启动前检查磁盘空间，不足时提示用户清理

### 加载策略

- 模型下载完成后自动加载到 sherpa_onnx
- 用户切换模型版本后重启生效
- 加载失败 → 错误提示 + 可重新下载

## 8. 后台任务与通知

- 文件转写通过 workmanager 注册为后台任务
- 长时间转写每 5 分钟做软 checkpoint（已完成的 segments 落盘）
- 转写完成后通过 flutter_local_notifications 弹系统通知
- 通知点击后跳转到对应笔记
- 后台转写中 App 被强制退出：转写状态持久化为 `transcribing`，下次启动时提示恢复

## 9. 边缘情况与错误处理

### 录音场景

| 场景 | 处理 |
|------|------|
| 麦克风权限被拒绝 | 弹引导对话框跳转系统设置；无权限时 UI 显示不可录音状态 |
| 麦克风被其他 App 抢占 | 捕获异常 → 自动暂停 → Toast 提示 |
| 系统休眠 / 合盖 | 监听睡眠通知 → 自动暂停 → 唤醒后恢复 |
| 长时间录音（数小时） | 每 5 分钟软 checkpoint，防数据丢失 |
| 长静音段落 | VAD 检测到长时间静音 → 弹出"要暂停吗？"提示 |
| 录音不讲话就停止 | 正常保存，生成可编辑空笔记 |
| 点击完成但缓冲区未处理完 | 停止采集 → flush 缓冲区 → 所有段处理完再保存 |

### 文件导入场景

| 场景 | 处理 |
|------|------|
| 不支持的格式 | 文件选择器 filter 限定格式；拖入非法格式 → 红框 + Toast |
| 文件损坏无法解码 | 捕获 ffmpeg 异常 → 提示"文件可能已损坏" |
| macOS sandbox 权限 | Security-scoped bookmark 读取失败时提示重新选择 |
| 全静音文件 | VAD 无语音段 → 提示"未检测到语音内容" |
| 文件极小（< 1s） | 正常走流程但提示"音频过短" |
| 导入和录音同时进行 | 文件导入走独立队列，互不干扰 |

### VAD 边界

| 场景 | 处理 |
|------|------|
| 背景噪音导致 VAD 不停 | 最小片段长度约束 + 灵敏度可调 |
| 语速极快导致碎片段过多 | 合并间隔 < 300ms 的相邻片段 |
| 非中英文内容 | SenseVoice 不支持时提示"暂不支持该语言" |

### 存储与数据安全

| 场景 | 处理 |
|------|------|
| 磁盘满 | 保存当前已完成内容 → 停止录音 → 弹提示 |
| 数据库损坏 | drift integrity check → 重建空库 → 提示部分数据可能丢失 |
| 音频文件被外部删除 | 笔记可读，但标注"音频文件不可用" |
| 并发写入 | drift 线程安全 + Repository 单点控制写入 |

### 用户交互边界

| 场景 | 处理 |
|------|------|
| 录音中开始新录音 | 弹确认框 → 保存当前 → 新建 |
| 转写中的笔记被删除 | 后台任务检查 note 是否存在，不存在则丢弃 |
| 编辑片段文字为空 | 保存时跳过，展示时过滤空段 |
| 导出时转写未完成 | 按钮置灰，显示进度百分比 |
| 同时打开多个笔记 | 支持（数据独立），但录音只能有一个激活任务 |

## 11. 非功能性要求

- **启动时间**：冷启动 < 3s（含模型加载）
- **实时转写延迟**：从说话完成到文字出现 < 1s
- **CPU/内存**：SenseVoice Small 模式下，macOS Intel/Apple Silicon 均流畅运行
- **模型热替换**：切换 ASR 模型时不阻塞 UI
- **包体积**：不含模型（运行时下载），App 本身 < 20MB
- **数据迁移**：drift 管理 Schema 迁移，用户数据不丢失
